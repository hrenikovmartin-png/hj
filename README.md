# Мамочке — с любовью ♡

Небольшой интерактивный сайт-поздравление ко Дню матери.

## Что внутри
- Адаптивная открытка с нежной анимацией и падающими лепестками.
- Письмо маме и шесть интерактивных карточек с признаниями.
- Меняющийся виртуальный букет.
- Скрытое послание-сюрприз.
- Поддержка клавиатуры, мобильных экранов и настройки уменьшения анимации.
- Никаких сборщиков, серверов, API-ключей или зависимостей — достаточно статического хостинга.

## Запуск локально
Откройте `index.html` в браузере.

## Публикация через GitHub Pages
1. Откройте **Settings → Pages** в репозитории.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Выберите ветку **main** и папку **/(root)**, затем нажмите **Save**.
4. Через минуту сайт будет доступен по адресу GitHub Pages, который покажет GitHub в этом разделе.

## Персонализация
Текст открытки находится прямо в `index.html`. Можно заменить формулировки на личные воспоминания и добавить имя в заголовок.
